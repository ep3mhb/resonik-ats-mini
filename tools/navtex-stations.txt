#   kHz NAVAREA letter | name | country | latitude | longitude | extra

# every four hours, at the turn its letter gives it (A at 00:00 UTC, B at
# 00:10 ... X at 03:50), so the times are not written here. Extra, when a
# station differs: t=HHMM,HHMM its own start times; f=HHMM its first start
# (then every four hours); n=text a note shown beside the name.

# what is on the air today and is followed here; Wikipedia's List of Navtex
# stations; and the station file of fldigi. Stations marked inactive,
# planned or unknown there are left out. Not for navigation.
